# カメラ選択の追加

## 変更

- 同意後にカメラ選択と一覧更新を利用できるようにした。未指定は既存の前面 / 背面設定に従い、指定時は `deviceId.exact` で要求する。
- カメラ名が未取得の場合、一覧更新の明示操作で許可用ストリームを一時取得し、成功・失敗にかかわらず全トラックを停止する。マイクは要求しない。
- 使用中のカメラ名を表示する。機器の選択を変える場合は停止 → 選択 → 開始とし、取得中・使用中は選択欄と一覧更新を無効にする。
- 既存の前面 / 背面切替では一覧の選択より `facingMode` を優先する。切替中は解析ループを止め、取得後に再開する。切替失敗・起動失敗時は残ったストリームを解放し、再試行できる表示に戻す。
- デバイス接続変更で一覧を更新する。選択した機器が利用できない場合は、他の機器へ自動起動せず、再選択を案内する。
- カメラの選択・デバイスIDはページ内のみで保持する。映像の保存・外部送信、保存セッション、CSV、回収設定の処理は変更していない。
- APIの確認資料: [W3C Media Capture and Streams](https://www.w3.org/TR/mediacapture-streams/)。

## 追記: push の依頼
