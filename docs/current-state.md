# Current state

最終更新: 2026-10-05

## 現在の状態

- ブランチ: `main`。push により GitHub Pages の公開ワークフローが実行される。
- 公開先: `https://mlabpages.github.io/reaction-meter/`。公開状態は GitHub Actions と公開ファイルの内容で確認する。
- 実装は `index.html` / `app.js` / `styles.css` を中心とする静的 Web アプリ。
- Face Landmarker と Pose Landmarker を使った表情・姿勢・視線の近似計測、CSV 出力、ブラウザ内セッション保存がある。
- 任意機能として `collector.gs` を Google Apps Script にデプロイし、`summary` / `timeseries` を回収できる。
- 同意画面、カメラの前面・背面切替、基準計測、マーカー、自己報告との相関表示が README に記載されている。
- 同意後に内蔵・USBカメラなどの一覧を表示し、開始前に使用するカメラを選択できる。名前が取得できない場合は「カメラ一覧を更新」で許可用に一時起動し、一覧取得後に停止する。
- 指定したカメラは `deviceId.exact` で要求する。使用中は一覧の変更を無効にし、停止 → 選択 → 開始で変更する。従来の前面 / 背面ボタンは使用中にも利用できる。
- 選択とデバイスIDはページ内のみで保持する。保存済みセッション・CSV・外部回収の形式は変更していない。

## 既知の注意点

- カメラ API は HTTPS またはローカルサーバーが必要で、`index.html` の直接起動では動かない。
- 視線・感情・姿勢の値は照明、角度、個人差などの影響を受ける近似値である。
- ブラウザ内のセッションはサイトデータ削除で失われるため、分析前に CSV を保存する。
- Google Apps Script の URL を公開リポジトリへ書く運用や、回収先を誤配布する運用には注意する。
- 選択したカメラが接続されていない場合はエラーを表示し、自動で別のカメラを起動しない。接続の確認と一覧更新・再選択が必要。
- PC / スマホ幅の表示と模擬カメラでの主要操作は確認済み。実カメラ、実モデルの推論、iPhone / Safari は今回未検証。

## 次に確認すること

- 変更時は、対象指標が CSV・サマリー・画面表示・任意回収のどこまで影響するかを確認する。
